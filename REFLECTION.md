# Admin Dashboard Reflection

This project was a great opportunity to put the knowledge from the lessons on grid into practice. It was especially useful in helping me distinguish when to use grid and when to use flexbox. Furthermore, despite it not being the point of the project, I also managed to learn a bit about using the svg element, which I previously wrongly assumed wasn't much different from the img element.

I really enjoyed using grid and I can see how I can make use of it in future projects. Having a good understanding of it has made the issue of layout much simpler for me and solved a lot of the issues I have previously had when trying to assemble layouts I envisioned in the past.

While working on this project, it has also occured to me that I completely forgot about what units are ideal for each style/element. For the most part I ended up using rem and pixels for almost everything, while mostly ignoring em. So that is something I will definitely have to go over.
